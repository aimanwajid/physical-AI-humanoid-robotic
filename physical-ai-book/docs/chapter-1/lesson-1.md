# Lesson 1: Introduction to Physical AI Concepts

This lesson introduces the core concepts of Physical AI, including its definition, key components, and applications. It will cover the basics of robotics, sensors, and actuators in the context of AI.

## Hello World Example

Let's start with a simple "Hello, World!" example in Python, which is a common language for Physical AI projects.

```python title="hello_world.py"
print("Hello, Physical AI World!")
```

**Instructions:**
1. Save the code above as `hello_world.py`.
2. Open your terminal or command prompt.
3. Navigate to the directory where you saved the file.
4. Run the script using `python hello_world.py`.

**Expected Output:**
```text
Hello, Physical AI World!
```
